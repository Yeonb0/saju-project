# PD 전달: 정책 v2 추가 수정 요청

기준 문서: 정책 v2 3종 및 PD 10/13 2차 답변. 이후 사용자 결정인 ‘90일 안에 이용 신청, 기한 내 접수된 생성 작업은 계속 처리’를 반영합니다. 이미 공유된 계정 운영 안내나 B 답변은 재수록하지 않습니다.

## 1. 선물 최초 사용 기한을 ‘결과 수령’이 아닌 ‘이용 신청’으로

현재 약관 7조의 ‘결제 후 90일 안에 처음 열어야 하며’는 단순 링크 접속인지, 정보 제출인지, 완성된 결과 수령인지 모호합니다. 기한 직전에 신청한 이용자가 서버 생성 지연 때문에 권리를 잃지 않도록 기준을 바꿉니다.

권장 문구:

> 선물은 구매 후 90일 이내에 수신 정보를 제출하고 이용을 신청해야 합니다. 기한 내 접수된 요청은 생성 처리가 끝난 뒤 제공되며, 완성된 콘텐츠를 최초로 제공받은 날부터 90일 동안 다시 볼 수 있습니다. 받는 분이 로그인해 선물을 계정에 연결하면 회원의 콘텐츠 보관 정책을 따릅니다.

- 단순 링크 접속만으로 이용 신청이나 최초 제공이 된 것은 아닙니다.
- 90일이 지난 뒤 새로운 신청은 받지 않지만, 기한 내 접수된 동일 요청은 재개합니다.
- 24시간은 고객 권리를 소멸시키는 추가 만료일이 아니라 생성 지연을 운영 확인으로 보내는 내부 기준입니다.
- 생성·제공 실패는 상태 확인과 기존 보상 정책으로 처리하며 무한 대기 또는 자동 완료로 안내하지 않습니다.
- 재열람 기한은 정보 제출·생성 시작·링크 재발급일이 아니라 완성된 콘텐츠 최초 제공일부터 계산합니다.
- A의 접수·제공·기한 port를 추가하지만 실제 B 콘텐츠 저장/제공·공개 수신 화면 연결은 별도입니다. 서비스 연결 완료라고 표시하지 않습니다.

## 2. 개인정보처리방침 2조의 선물 보관 기준

전화번호와 콘텐츠용 정보를 분리한 v2 방향은 유지합니다. 다음처럼 실제 기능 종료 시점을 반영해 주세요.

| 항목 | 문구 제안 |
|---|---|
| 선물 수신 전화번호 | 구매 후 30일까지 발송·재발송 목적으로 보관하고 종료 후 파기. 취소 등으로 목적이 먼저 종료되면 더 일찍 파기 |
| 수신자 생년정보 | 기한 내 이용 신청이 없으면 신청 기한 종료 후 파기. 신청한 경우 콘텐츠 제공·재열람에 필요한 최소 기간만 보관. 계정 연결 시 회원 정보 정책에 따름 |
| 선물 메시지·수신자/발신자 표시 이름 | 신청이 없으면 신청 기한 종료 후 파기. 접수된 요청은 처리 완료 및 재열람 기간에 맞춰 보관. 계정 연결 시 해당 회원의 보관 정책에 따름 |

- 기한 내 접수됐지만 생성 중인 정보를 구매 후 90일에 먼저 지우면 안 됩니다.
- 생년정보 원본이 결과 제공 후에도 필요한지는 B 생성·재열람 흐름과 확인하고, 불필요하면 열람 기한보다 일찍 삭제할 수 있습니다.
- 계정 연결된 선물의 A 메시지 정리는 수신자 탈퇴 상태를 따라 삭제 대상으로 전환합니다. B의 회원·생년정보·콘텐츠 파일 삭제까지 이번 A 변경으로 완료되는 것은 아닙니다.
- 개인정보 삭제 worker, 공급자 사본·백업 처리까지 준비하기 전 ‘모든 사본이 정확히 만료 순간에 삭제된다’고 보장하지 않습니다. 삭제 오류는 운영 확인이 필요합니다.
- 구매자의 탈퇴와 선물을 연결한 수신자의 탈퇴는 다릅니다. 선물이 다른 회원에게 귀속된 경우 구매자의 탈퇴만으로 그 수신자의 콘텐츠까지 삭제하지 않도록 정책을 구분해야 합니다.

## 3. 알림톡 재발송뿐 아니라 링크 재발급도 30일 종료

약관 7조·환불정책 8조의 재발송 안내에 현재 알림톡 기반 재발급도 함께 적어 주세요.

> 선물 알림톡 재발송과 알림톡을 통한 링크 재발급은 구매 후 30일 이내에 신청할 수 있습니다. 기간이 지나면 이미 받은 유효한 링크로 이용할 수 있으며, 알림톡으로 새 링크를 받을 수 없습니다.

서버 경계는 실제 구매 차감 시각부터 30일 미만입니다. 날짜를 ‘30일째 자정까지’로 다르게 안내하지 않습니다. 재발급은 구 링크를 폐기하며 콘텐츠 이용 기한을 연장하지 않습니다. 재발송은 주문별 재발급과 합산 하루 3회·1분 간격입니다.

## 4. 선물 취소는 ‘열어보지 않음’ 대신 ‘최초 제공 전’

환불정책 8조 권장 문구:

> 구매 후 7일 이내이고 완성된 운세 결과 또는 부적이 아직 제공되지 않았다면 선물을 취소할 수 있습니다. 단순 링크 접속이나 수신 정보 제출만으로 제공이 시작된 것으로 보지 않습니다. 취소하면 사용한 유료·보너스 등껍질을 원 지급분과 원 유효기간으로 돌려드립니다.

신청·생성과 취소가 겹치면 서버가 원자적으로 판단합니다. 최초 제공 후에는 일반 취소를 제한하되 법령상 예외까지 일괄 배제하지 않습니다.

## 5. 승인 즉시 지급·구매 즉시 제공 문구 보완

환불정책 2조·약관 6조:

> 등껍질은 결제 승인 확인 후 회원 계정에 지급됩니다. 처리 지연 시 주문 조회에서 진행 상태를 안내합니다.

약관 7조:

> 유료 콘텐츠는 구매 후 생성이 완료되면 제공됩니다. 처리 중인 경우 진행 상태를 안내하며, 생성 실패 시 사용한 등껍질은 처리 결과에 따라 반환합니다.

승인 응답 유실·결과 불명·지급 처리 중에는 미청구 또는 미지급을 일괄 단정하지 않습니다. 최종 완료는 서버의 영속 결과를 따릅니다.

## 6. 잔여 유료분 환불 표현 보완

환불정책 5조의 ‘남은 유료 등껍질’은 ‘유효기간이 남은 유료 등껍질’로 명확히 해 주세요. 현재 일반 관리자 환불은 해당 충전의 유효한 잔여 유료분 전체를 정산합니다.

- 1개당 100원은 현재 충전 상품과 일치합니다. 할인 상품을 추가하면 실제 결제액 기반 비례 계산과 문구를 재검토합니다.
- 서비스 종료·미성년자 등 법정 예외를 일반 만료/잔여분 조건만으로 거절하지 않습니다. 별도 예외 처리 경로는 미완료입니다.
- 신청 기반·수수료 없음·남은 보너스 회수·사용 보너스 미청구 결정은 유지합니다.

## 7. 미성년자 결제와 3영업일 처리

- 미성년자 결제 허용·별도 충전 한도 없음은 유지합니다. 법정대리인 동의 필요성과 동의 없는 계약의 취소 가능성을 결제 전에 안내합니다.
- 안내만으로 실제 보호자 동의를 확인했다고 간주하지 않습니다. PG 계약 요건·구체적 확인 방식·사용분 취소 예외는 출시 전 확인이 필요합니다.
- 본인이 취소를 신청하는 경우까지 ‘법정대리인임을 확인하는 자료’를 일괄 요구하지 않도록 다음 문구를 제안합니다.

> 신청 유형에 따라 본인 또는 법정대리인 여부를 확인하는 데 필요한 최소 자료를 안내하며, 확인 후 처리합니다.

- 3영업일은 결과 이메일 안내만의 기한으로 오해되지 않게 환불 처리와 안내를 구분합니다. PG·결제수단의 실제 반영 지연도 별도 안내합니다. 법정 청약철회에 적용되는 환급 기한은 준수해야 합니다.
- 이메일 자동 발송·영업일 계산이 구현돼 있다는 뜻은 아닙니다. 담당자 접수·기한·결과 안내 관리가 필요합니다.

## 8. 탈퇴·공급자 표의 남은 확인

- ‘탈퇴하면 불필요한 개인정보를 지체 없이 파기’ 방향은 유지합니다. 현재 B 회원 익명화의 일괄 30일 보관은 아직 변경하지 않았으므로 담당 구현과 맞춰야 합니다.
- A는 계정 연결된 선물의 불필요한 메시지·이름·발송 정보를 탈퇴 상태에 맞춰 정리하도록 연결합니다. 법정 금융 증거는 별도로 보존합니다.
- BE·DB·파일 저장 업체 법인명·저장/접근 국가·리전은 실제 계약·설정을 확인한 뒤 채웁니다. 업체 국적만으로 국외 이전 여부를 판단하지 않습니다.
- v2 주석의 ‘해외 업체가 아니면 6조에서 삭제’는 ‘실제 국외 저장·처리·접근이 없는 것으로 확인되면 해당 국외 이전 행을 제외’로 수정해 주세요.
- PostHog·Sentry 보관·분석 제외와 공급자/백업 파기는 실제 설정 확인이 필요합니다.

## 정리

핵심 새 결정은 ‘90일 내 이용 신청을 보호하고, 24시간은 내부 운영 확인 기준으로 사용’입니다. 전화번호 30일과 최초 제공 후 90일 재열람은 그대로 유지합니다. 개인정보 삭제·실패 보상·계정 연결은 실제 담당 구현과 함께 맞추며, 문구 수정만으로 법률 검토·운영 준비가 완료된 것으로 표시하지 않습니다.

참고 법령: [전자상거래법 제17조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031805921), [제18조](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029561427). 이 전달 문서는 법률 검토 결과를 대신하지 않습니다.
