# 오늘의 운세 데이터 (BE 전달용) — 2026-10-15 PD

## 규칙

- 화면 항목: **행운 지수(서버 · 만세력 기준) + 수호 동물 + 행운 미션 + 행운 초성 + 행운 노래**
- 행운 지수는 서버에서 계산하는 값이라 이 문서에 없음
- 나머지 4개는 아래 목록에서 **userId + 한국 날짜(KST)** 로 항목마다 1개씩 고정 랜덤 (같은 날 새로고침해도 같음)
- 서버의 행운 색 · 아이템 · 장소는 화면에 쓰지 않음
- 문구는 뿌기 말투(반말)
