# 부적 조합 (BE 전달용) — 2026-10-15 PD

## 조합 규칙

- 부적 1장 = **오행(색) + 테두리 + 배경지 + 12지 동물 + 아이템 + 4글자 멘트 + 도장**
- **오행**: 사주에서 가장 부족한 오행 1개 (같은 사람이면 항상 같음)
- **테두리 · 배경지**: 그 오행의 테두리 3종, 배경지 3종 중 각각 랜덤 1개 → 오행당 9가지, 전체 45가지
- **12지 동물**: 12마리 중 랜덤 1마리
- **아이템**: 운세 종류별 3개 중 랜덤 1개
- **멘트**: 운세 종류별 7~10개 중 랜덤 1개
- **도장**: 공통 1종 `seal_default`
- 생성할 때 한 번 뽑아서 결과에 저장 (다시 열어도 같은 부적)
- 운세 종류 key: `csat` 수능운 · `general` 종합운 · `love` 애정운 · `wealth` 재물운 · `match` 궁합 · `sinsal` 신살
- **미정** 표시된 칸(색 코드 · 테두리 · 배경지 디자인 · 아이템 내용)은 정해지면 채울게요. key는 그대로 써 주세요.
