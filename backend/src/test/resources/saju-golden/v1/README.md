# 사주 계산 회귀 fixture v1

이 fixture는 실제 사용자 정보를 포함하지 않는 합성 입력만 사용한다. `policyVersion`은 실행 중인 계산 정책과 반드시 같아야 하며, 다르면 test가 실패한다.

현재는 엔진 회귀를 고정하기 위한 초안이다. 명리 검수자와 독립 만세력으로 확인한 provenance를 추가하기 전에는 계산 정확성의 외부 인증 근거로 사용하지 않는다. 다음 확장 때 일반 양력, 음력·윤달, 절입 전후, 23:00~00:59, 시각 미상, 지원 날짜 경계의 검수 사례를 100건 이상으로 늘린다.
